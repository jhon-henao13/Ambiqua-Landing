# 🌿 Ambiqua Landing

**Ambiqua** es un proyecto **AgriTech IoT** enfocado en la **automatización de sistemas de riego inteligentes** para optimizar el uso del agua y mejorar la productividad agrícola.  
Esta landing page presenta el proyecto de forma visual, moderna y totalmente responsiva.

---

## 💡 Descripción General

Ambiqua es una solución de **riego automatizado inteligente** basada en **tecnología IoT**, desarrollada como **proyecto productivo articulado con el SENA (Servicio Nacional de Aprendizaje) – Colombia**.

El sistema permite a los usuarios monitorear variables agrícolas como **humedad y temperatura del suelo**, y controlar el **riego de forma remota o automática** desde cualquier dispositivo mediante una **aplicación web progresiva (PWA)** conectada a un **módulo ESP32** por protocolo **MQTT**.

Esta landing page comunica la visión, funcionalidades y beneficios del proyecto.
